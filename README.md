# HootOut: A web application for Instant Messaging

HootOut is a real-time messaging application.

Send direct messages to friends or join a Server to chat with multiple people. Organize your conversations in Channels and send messages to other Server members.

In this version 0.1, Users can register an account with a username, email and password. Users can create a Server, create a Channel inside a Server and invite other Users to a Server. Users can send messages in Channels in real time, including images, audio, documents and video files.

More features are planned for version 0.2:

- Direct messages between Users
- Server permission and role management
- Connection status
- User commands and Third party tools integration.

**This is a work in progress.**
